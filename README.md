# Nome do Projeto
Painel de Notas

# O que é o projeto?
    O projeto é um painel de notas, no qual informa:
        - Nome;
        - Turma;
        - Média de todas as disciplinas;
        - Situação do aluno: aprovado, recuperação e reprovado.

# Qual problema ele resolve?
    - Informa os erros dos arquivos;
    - Com base nos arquivos, recolhe as informações importantes.
   
# Para quem foi desenvolvido?
    -Para intituições de ensino, tendo como objetivo informar informações academicas dos alunos.

# Funcionalidades

- Cálculo de média de cada aluno;
- Cálculo de média de cada disciplina;
- Sintetizar informações dos alunos/ diciplina;
- Apresentação da situação dos alunos;
- Registro de erros nos arquivos de dados.
